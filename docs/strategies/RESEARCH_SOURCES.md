# Research sources

Accessed 2026-08-18. Only sources that actually contributed entries are listed.
Every strategy description in the catalog is written from scratch; no source text
is reproduced.

**Licensing note.** The CrossSection repository is GPL-2.0. Its CSV is deliberately
**not** vendored into this repository. Only factual citation metadata (signal name,
authors, year, journal, category) was extracted, and each catalog entry cites the
original paper rather than the index.

## Search terms used

Catalogue-style queries (`complete list stock trading strategies`, `technical analysis
strategies`, `candlestick patterns complete list`), family-specific queries
(`statistical arbitrage`, `pairs trading variations`, `calendar anomaly`, `factor
investing`, `execution algorithms TWAP VWAP implementation shortfall`), and
academic-index queries (`Chen Zimmermann open source asset pricing`, `Hou Xue Zhang
replicating anomalies`). The academic indexes proved far higher yield than the
listicle-style sources, which repeat the same twenty or so retail strategies.

## What was deliberately not used

- Paywalled or proprietary strategy code.
- Vendor "signal" marketing pages with no stated rules.
- Any source whose rules could not be stated precisely enough to implement or to
  describe as a documented concept.
