# Strategy taxonomy

Two levels: category, then subcategory. Ids are `category.family.variation`,
so `trend.ma-crossover.sma-50-200-long` reads as trend following, moving-average
crossover family, the 50/200 simple long-only variation.

A variation is kept separate only when it changes behaviour — indicator, period,
direction, confirmation, holding rule or regime. Renaming alone never creates an entry;
alternative names are recorded as aliases and resolve to the same record.
